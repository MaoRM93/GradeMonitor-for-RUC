# GradeMonitor — macOS 成绩自动监控工具

再也不用每天刷教务系统了！这个小工具帮你自动查成绩。

成绩更新第一时间通知你，排名变化心中有数，优雅又省心。

考完试，最让人头疼的是什么？不是考试，不是论文——而是每天反复登录教务系统，一遍遍刷新成绩页面，生怕错过任何一门出分。

GradeMonitor 是一款适配 macOS（Windows 支持 planning 中）的成绩排名自动检测工具，安装后默默在后台工作，出分了就发通知告诉你，省下大把刷网页的时间。

## 它是怎么工作的？

本程序会按照你设定的时间间隔，自动登录教务系统查询成绩和排名。

一旦检测到**新出成绩**或**排名变化**，立即通过 macOS 原生通知推送到你的桌面。

也支持简洁模式！仅提示「您有成绩或排名更新」这几个字，保护隐私，保护心灵。你唯一需要做的事：看一眼通知，继续做自己的事。

## 核心功能一览

### 自动监测
- 支持**成绩监测**和**排名监测**，可独立开关
- 可设定监测时间窗口（如 08:00–23:00），深夜不打扰，窗口外自动休眠
- 监测间隔可自定义（300–3600 秒），避免对学校服务器造成过大负担

### 通知推送
- **详细模式**：直接在通知中显示课程名、绩点、专业排名、班级排名变化
- **简洁模式**：仅提示「您有成绩或排名更新」，保护隐私

### 排名可视化
主界面实时展示**专业排名**和**班级排名**，无需登录教务系统即可查看。

### 更新检查
内置应用更新检查（每 1 小时自动检查一次，也可手动触发），发现新版本时弹窗提示并引导下载。

### 其他特性
- **开机自启动**：通过 macOS 原生登录项机制实现，可在「系统设置 → 通用 → 登录项与扩展」中随时管理
- **菜单栏图标**：在顶部菜单栏显示小图标，点击可快速打开主界面或退出程序
- **深色模式适配**：自动跟随系统深色/浅色模式切换，夜间使用不刺眼

## 如何使用？

### macOS 端

1. 下载 `GradeMonitor.app`，拖入「应用程序」文件夹
2. 首次打开时，请在 Finder 中右键点击 App → 选择「打开」，确认运行
3. 在界面上方填写学号和密码（可勾选记住密码）
4. 勾选需要监测的项目，设置时间范围和间隔
5. 点击「启动自动监控」，然后关闭窗口——程序会在后台默默工作
6. 等待通知

> 关闭窗口不会退出程序。如需彻底退出，请通过菜单栏图标选择「退出」或按 `Command + Q`。

## 面向开发者：从源码构建

### 技术栈

| 层 | 技术 |
|---|---|
| 桌面前端 | Flutter（macOS） |
| 本地后端 | Python FastAPI + uvicorn（`127.0.0.1:18923`） |
| 更新分发 | GitHub Releases |
| 源码仓库 | [MaoRM93/GradeMonitor-for-RUC](https://github.com/MaoRM93/GradeMonitor-for-RUC) |

### 构建前端（.app）

```bash
cd frontend
flutter pub get
flutter build macos --release
# 产物：build/macos/Build/Products/Release/GradeMonitor.app
```

### 启动后端

```bash
pip install -r backend/requirements.txt
uvicorn backend.api.app:app --host 127.0.0.1 --port 18923
```

### 版本号体系

- 完整版本：`107.0.0.135`（`pubspec.yaml` 中 `version: 107.0.0+135`）

- 更新检查指向的仓库：`MaoRM93/GradeMonitor-for-RUC`（同上文件中的 `repoOwner` / `repoName` 常量，GitHub 仓库更名后需同步修改）
