# GradeMonitor — 适用于 RUC 教务系统的成绩自动监控工具

现已推出：macOS 端 **2026 年秋季更新 108.0.0.100** 版本。Windows 端正在开发中，请您继续使用 **107.0.0.125 LTS** 版本，更新敬请期待。

相较于以前的 6.0 和 107.0 系列版本，这一大版本重新构思了程序设计，优化了用户体验，并增加了一系列实用工具。

GradeMonitor 是一款适配 **macOS 与 Windows** 的成绩排名自动检测工具。安装后，程序会根据您的设置在后台运行，成绩发布后及时发送通知，省去反复刷新教务系统网页的时间。

此外，程序还可以帮助您整理、分析和排序各个科目、各个学期的成绩，并支持按照指定规则一键筛选「核心绩」。

## 系统要求

- macOS 13 及以上（仅支持 Apple Silicon / M 系列芯片）；推荐使用最新版 macOS 27。
- Windows 10 64 位，版本 1809 及以上（x64）；推荐使用最新版 Windows 11 26H2。

## 如何使用？

### Windows 端

1. 下载当前适用的 Windows 版本安装包 `GradeMonitor_107.0.0.125_Windows_x64.zip`，解压后双击运行 exe 安装包，按向导完成安装（无需管理员权限）。
2. 启动 GradeMonitor，在设置页填写学号和密码（可勾选记住密码）。
3. 勾选需要监测的项目，设置时间范围和间隔。
4. 点击「启动自动监控」，然后关闭窗口——程序会在后台默默工作。
5. 等待通知。

> 关闭窗口不会退出程序。如需彻底退出，请通过系统托盘图标选择「退出」。

### macOS 端

1. 下载 `GradeMonitor_108.0.0.100_macOS_arm64.zip`，解压后将 `GradeMonitor.app` 拖入「应用程序」文件夹。
2. 首次打开时，请在「应用程序」文件夹或启动台中找到 App，右键点击并选择「打开」，然后确认运行。
3. 在界面上方填写学号和密码（可勾选记住密码）。
4. 勾选需要监测的项目，设置时间范围和间隔。
5. 点击「启动自动监控」，然后关闭窗口——程序会在后台默默工作。
6. 等待通知。

> 关闭窗口不会退出程序。如需彻底退出，请通过菜单栏图标选择「退出」或按 `Command + Q`。
